Fuente de tasas

Para tasas automáticas verificadas, introduce la URL HTTPS de tu API propia o intermediario con CORS. Debe responder JSON: {"USD":123,"EUR":145,"USDT":130,"date":"2026-10-17","source":"..."}. Sin API no inventamos tasas.

Como alternativa puedes registrar tasas verificadas manualmente; se marcarán como manuales.

Mi perfil

Los datos se guardan por perfil en este dispositivo. No se sincronizan con otros teléfonos. Para autenticación real se requiere configurar un proveedor como Firebase.

Instalar aplicación

En Android abre el menú del navegador y elige «Instalar aplicación». En iPhone, Safari → Compartir → Añadir a pantalla de inicio. Usa GitHub Pages con HTTPS.
